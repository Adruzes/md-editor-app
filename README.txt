MDノート — 軽量Markdownエディタ
====================================

これはインストール不要・Python不要・VSCode不要の、
Markdown専用の「アプリっぽいウィンドウ」で動く編集ツールです。
Google Chrome または Microsoft Edge があれば動きます。

■ 起動方法
  Windows: 「start_mdnote.exe」をダブルクリック（推奨）
           ※ .batファイルより自然な「アプリ起動」の見た目・挙動になります。
           ※ 署名なしの実行ファイルなので、初回はWindowsの
             「WindowsによってPCが保護されました」という警告が出ることが
             あります。その場合は「詳細情報」→「実行」を選べば起動できます。
           代わりに「start_mdnote.bat」でも同じことができます。
  Mac    : 「start_mdnote.command」をダブルクリック
           （初回は右クリック→「開く」を選ぶ必要がある場合があります）

  これらのランチャーは Chrome/Edge を「--app」モードで起動します。
  アドレスバーやタブのない、独立したアプリのようなウィンドウが開きます。

  ※ ランチャーがうまく動かない場合は、index.html をブラウザに
    ドラッグ＆ドロップしても普通に使えます（見た目は通常のタブになります）。

■ できること
  - 📁 フォルダを開く：VSCodeのように左側にファイルツリーを表示
  - 📄 ファイルを開く／＋ 新規：1ファイルだけ編集
  - シンタックスハイライト付きのエディタ（CodeMirror）
  - 編集／分割／プレビューの3表示切替
  - 🌙 ダークモード／ライトモード切替
  - 💾 保存 (Ctrl+S)：開いた元のファイルに直接上書き保存
  - 📕 PDF出力：今の内容をそのままPDFとしてダウンロード（印刷ダイアログなし）

■ 「フォルダを開く」「上書き保存」について
  Google Chrome / Microsoft Edge（比較的新しいバージョン）では、
  「File System Access API」という機能を使って、選んだファイルに
  直接、上書き保存できます。

  もし古いブラウザやFirefox/Safariで開いた場合は、この機能が
  使えないため、フォルダの中身は見られますが「保存」は毎回
  ダウンロードフォルダに新しいファイルとして書き出す形になります。
  （その場合は元のファイルをダウンロードしたファイルで
  手動的に置き換えてください）

■ データはどこにも送信されません
  このアプリは完全にオフラインで動作し、通信は一切行いません。
  編集内容やファイルの中身がインターネットに送られることはありません。

■ フォルダ構成
  index.html   … アプリ本体
  style.css    … 見た目
  app.js       … 動作ロジック
  libs/        … 同梱ライブラリ（CodeMirror / marked / DOMPurify / html2pdf.js）
  start_mdnote.exe … Windows用ランチャー（実行ファイル・推奨）
  start_mdnote.bat / .command … ランチャー（.batはWindows用の代替、.commandはMac用）

■ カスタマイズ
  普通のHTML/CSS/JSファイルなので、色やフォントを変えたくなったら
  style.css を好きに編集してOKです。
